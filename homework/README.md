# Michael 写作课 · 课后作业提交系统

Class 1–8 的课后作业与写作模考提交页。内容逐条转录自八份《Michael写作 class N·课后助教安排》
原始文档（class 1–2 为 PDF，class 3–8 为 DOCX）。

这些是**独立的静态 HTML 文件**，不属于 Next.js 应用，也没有构建步骤 —— 双击打开即可用，
也可以直接丢到任何静态服务器上。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 总入口。顶部按课次切换（Class 1–8），一页覆盖全部八次课 |
| `class1.html` … `class8.html` | 单课页面。只显示该课次，适合按天单独发给学生 |
| `assets/lessons.js` | 全部课程内容（模考题目、听写词表、四项作业） |
| `assets/app.js` | 渲染、保存、确认、生成报告 |
| `assets/styles.css` | 样式，含深色模式与打印样式 |

## 学生怎么用

1. 填写姓名和日期。
2. 按页面顺序逐步完成：**模考 → 听写 → 作业 1–4**。顶部进度条显示还剩几项，
   底部「跳到下一步」直接跳到下一个未提交的部分。
3. 每一部分底部都有「确认提交」。点一下就会记录时间并显示 `✓ 已收到 · 时间戳`。
4. 全部确认后点「生成本课报告」（或「全部课次报告」），在打印对话框里选择
   **另存为 PDF** 保存。

作答会随时自动保存在本机浏览器里（`localStorage`），关掉页面再打开还在。
换设备或换浏览器不会同步 —— 请在同一台设备上完成，并及时导出 PDF。

## 设计上的几点

- **只收集，不批改。** 页面里没有任何评分、判分或答案校验逻辑；报告把学生写的内容原样收录，
  未填的地方标为「（未填写）」，方便助教一眼看到缺口。
- **听写成绩由学生自填**，是提交记录的一部分，不是系统给的分数。
- **模考支持手写稿。** 可以誊写到文本框，也可以拍照上传（图片在浏览器内压缩到长边 1400px
  后随报告一起打印，不会上传到任何服务器）。若浏览器存储写满，页面会提示尽快导出 PDF。
- **Class 2 没有模考。** 原文档该次课后安排直接从作业开始，页面如实说明，不虚构环节。
- 每次课的听写词表、题目、作业要求都按原文档转录，包括 Class 3 的 70 词、
  Class 6 的搭配听写、Class 7 的句型／语法听写、Class 8 的 Task 1 图表语言听写。
